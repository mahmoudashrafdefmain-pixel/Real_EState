## 📌 نبذة تنفيذية عن المشروع (Executive Overview)

### بالعربية:
**منصة الاستخبارات العقارية والتقييم التنبؤي بالذكاء الاصطناعي (AI & GIS Real Estate Intelligence)**  
تحليل وتثمين أكثر من **33,000 أصل عقاري مصري** مع محرك تمويل بنكي متوافق مع **قواعد البنوك المصرية** ولوحة تحكم تنفيذية تفاعلية بدون تمرير (**Zero-Scroll Executive Dashboard**).

**هل تساءلت يوماً كيف يمكن لقرار استثماري بمليارات الجنيهات في سوق العقارات أن يتحول من «مجرد تخمين» إلى معادلة رياضية رابحة ومحسوبة بدقة 99.5%؟**
1. في سوق سريع التغير كالسوق العقاري المصري، انطلق هذا المشروع لبناء منصة ذكاء أعمال متكاملة (End-to-End Enterprise Platform) تستند إلى دراسة وتدقيق قاعدة بيانات ضخمة تضم **33,401 وحدة عقارية** عبر مختلف المحافظات.
2. تم إثراء البيانات بمؤشرات جودة الحياة والبيئة عبر دمج مؤشر نقاء الهواء العالمي (**US AQI**) ونسب المساحات الخضراء.
3. طُوّر محرك تسعير تنبؤي فائق التطور يعتمد على خوارزميات التعلّم الآلي المركبة (**Super-Ensemble**) محققاً دقة **99.46% (R² = 0.9946)** مع نسبة خطأ **2.13% (MAPE)**.
4. نظام محاكاة ائتماني وتمويلي كامل **متوافق مع قواعد البنوك المصرية** وسقف عبء الدين (DTI 30%-40%) لحساب جداول الإهلاك والأقساط الشهرية بدقة بالغة.
5. لوحة تحكم تنفيذية بفلسفة **(Zero-Scroll)** ونسبة عرض (70% بصري تفاعلي / 30% نصوص ورؤى تنفيذية) بهوية بصرية ملكية فاخرة (Dark Mocha & Antique Egyptian Gold) ودعم الوضع النهاري.
6. خريطة جغرافية تفاعلية مفتوحة المصدر (**Leaflet.js + Esri Geospatial Tiles**) تغطي **84 محوراً جغرافياً موثقاً**.
7. جناح متكامل لإحصاءات ذكاء الأعمال المتقدمة (**Statistics & BI Suite**) يضم **20 رسماً بيانياً ديناميكياً** مزوداً بشرح فوري لكل رسم.
8. مستكشف حي لقاعدة البيانات مع فلاتر متعددة الأبعاد وإمكانية تصدير الصفقات الذهبية (**Alpha Deals**) بصيغة CSV.

## 🛠️ التقنيات المستخدمة (Technology Stack)

- **Machine Learning & Data Science:** Python 3.12, Scikit-learn, LightGBM, Pandas, NumPy, Joblib
- **Geospatial & Mapping:** Leaflet.js, Leaflet-heat, Esri Geospatial Basemaps
- **Front-End & Executive UI:** Modern HTML5, CSS Grid/Flexbox, JavaScript (ES6+), Chart.js
- **Alternative BI Runner:** Streamlit 1.58, Plotly Express & Graph Objects
- **Quality Assurance & Testing:** Pytest (Comprehensive unit & regression test suites)

## 🚀 تشغيل المشروع محلياً (Local Setup & Run)

### 1. تشغيل لوحة التحكم التنفيذية مباشرة (HTML):
```bash
python run_dashboard.py
# أو الضغط مرتين على launch_dashboard.bat
```

### 2. تشغيل تطبيق Streamlit:
```bash
cd dashboard
streamlit run app.py
```

### 3. تشغيل الاختبارات الآلية:
```bash
pytest tests/ -v
```
